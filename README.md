# pairwise-ccd-collision

弓箭射向薄墙，箭矢每帧位移两米，薄墙只有五厘米厚，离散检测直接穿过去；扫掠球用起点到终点的一条线段，墙在侧面时没算到；箭矢带旋转，角速度让箭头在一帧内转过九十度，扫掠体没覆盖旋转体积；高速下弹性反弹按穿透深度算，箭矢被弹到墙后；触发器只检测中心点，箭擦着门框飞过也触发开关；移动平台每帧位移超过自身厚度，站在上面的角色掉下去；关节约束在高速下解算发散，角色手臂被拉长；网络同步只发最终位置，客户端在中间帧看不到碰撞，箭矢在客户端穿墙；地形高度图在陡坡处采样跳变，箭矢落地判定落到隔壁格子；连续碰撞的迭代次数按固定 4 次，连续薄板需要 20 次仍穿透。gameplay/ccd_collision.py 是核心，tests/test_ccd_collision.py 15个红。要修的是：扫掠体检测；侧面扫掠；旋转体积覆盖；按时间反弹；触发器体积；平台扫掠；关节高速约束；同步碰撞事件；地形双线性采样；按距离自适应迭代。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
